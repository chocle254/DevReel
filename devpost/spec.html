1. How This Works, In Plain Language

DevReel takes a public GitHub repository and turns the software inside it into a short cinematic project explanation. It reads the actual source code as evidence, understands the project's purpose and system flow, creates a story and visual plan, renders that plan as controlled React/HTML/SVG animation, records the animation with Playwright, and assembles narration and music with FFmpeg.

GitHub

Core principle: AI decides what should be communicated. DevReel decides how that communication is rendered.

10. Important Failure Modes

Invalid URLReject before generation and explain how to correct it.
Repository inaccessiblePrivate, deleted, unavailable, or unclonable repositories become failed jobs.
Repository too largeExplicit limits stop excessive processing.
AI failureValidate structured output and allow one controlled retry.
Rendering failurePlaywright capture errors become a failed generation.
FFmpeg failureAssembly failure prevents false completion and triggers cleanup.
Storage failureB2 upload can retry; completion requires successful storage.

11. What Was Simplified and Why

  • No authentication — keeps the PoC focused.
  • Public GitHub repositories only — avoids GitHub permission complexity.
  • Curated music — avoids unnecessary runtime music-search complexity.
  • No sound effects — narration, animation, and music prove the audiovisual concept.
  • No full video editor — automated explanation is the differentiator.
  • No generative video model — structured animation is cheaper, controllable, and consistent.
  • Limited scene library — makes visual quality easier to maintain.
  • Representative repositories — proves the general approach without claiming perfect every-repo support.
  • No production accounts, billing, teams, or enterprise controls.

Open implementation issues

  • Validate Railway resources once Playwright and FFmpeg run together.
  • Confirm the exact NVIDIA TTS request/response shape during implementation.
  • Use a short-lived token for protected renderer access.
  • Choose repository limits based on actual PoC workloads.
  • Expose window.__DEVREEL_READY__ = true only after fonts, assets, scene data, and initial animation state are ready.
Final architecture: AI understands software and decides how that software should be explained; a controlled renderer turns that explanation into a polished audiovisual story.
